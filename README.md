This is a personal portfolio created exclusively to showcase my books. It features a fully interactive 3D book representation built entirely from scratch with mathematics and perspective rendering.

### Tools Used
- **React**: For component structure and UI state.
- **Vite**: For lightning-fast module bundling and development.
- **Vanilla CSS**: Used extensively for all layout, responsive design, and complex 3D transformations.
